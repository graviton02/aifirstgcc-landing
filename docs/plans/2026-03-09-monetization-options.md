# Monetization Options — Future Reference

> **Date:** 2026-03-09
> **Status:** For future consideration (everything is free for now)

---

## 1. Freemium Claim + Paid Features

**How it works:** Claiming a company profile is free. Premium tier unlocks advanced features.

**Free tier (current):**
- Claim profile
- Edit company/agent info (with admin approval)
- Invite team members

**Premium tier (future):**
- Featured placement in directory (higher ranking, "Featured" badge)
- Analytics dashboard (who viewed your agents, which buyers shortlisted, search impressions)
- Lead gen data (contact info of buyers who shortlisted your agents — with buyer consent)
- Priority admin review (edits approved faster)
- Custom branding on profile (banner image, custom colors)
- Verified badge

**Pricing model:** Monthly/annual SaaS subscription per company ($99-499/mo depending on tier)

**Pros:** Low barrier to claim (drives adoption), recurring revenue, scales with value delivered
**Cons:** Need to build analytics infrastructure, requires enough traffic to make analytics valuable

---

## 2. Lead Generation / Matchmaking Fee

**How it works:** Directory is free. Revenue comes when a buyer connects with a provider through the platform.

**Options:**
- **Per-lead fee:** Charge providers $X per qualified lead (buyer contact request)
- **Per-intro fee:** Charge when an actual introduction/meeting is facilitated
- **Success fee:** Charge a percentage of deal value if a contract is signed (hardest to track)

**Pricing:** $50-500 per lead depending on deal size potential

**Pros:** Aligns revenue with value delivered, providers only pay when they get something
**Cons:** Requires tracking lead quality, providers may circumvent the platform after first contact

---

## 3. Advertising / Sponsored Placement

**How it works:** Charge providers for visibility within the directory.

**Options:**
- **Sponsored agent cards:** Appear at top of search results / category pages with "Sponsored" label
- **Banner ads:** On category pages, comparison pages, homepage
- **Featured company spotlight:** Rotating featured companies on homepage
- **Category sponsorship:** "Customer Experience agents — powered by [Company]"

**Pricing:** CPM (cost per thousand impressions) or flat monthly fee ($500-5,000/mo)

**Pros:** Immediate revenue, doesn't require user conversion, scales with traffic
**Cons:** Can degrade user experience if overdone, need significant traffic volume

---

## 4. Pay-to-Claim (Gated Access)

**How it works:** Claiming itself requires a subscription.

**Free (unclaimed):**
- Company data visible in directory (from scrape)
- "Claim this profile" CTA visible

**Paid claim ($X/mo):**
- Edit access to company and agent profiles
- Team management
- Analytics
- Contact requests from buyers

**Pricing:** $99-299/month

**Pros:** Revenue from day 1, clear value prop ("control your presence")
**Cons:** Friction reduces claim rate, companies may not see value until directory has traffic

---

## 5. Buyer-Side Premium

**How it works:** Charge enterprise buyers for advanced features.

**Free buyer account:**
- View full agent details
- Compare agents
- Shortlist

**Premium buyer ($X/mo):**
- Unlimited comparisons (free tier limited to X/month)
- Export comparison reports (PDF)
- Priority contact requests
- Custom shortlist sharing with team
- API access to directory data
- Personalized agent recommendations

**Pricing:** $49-199/month per seat, or enterprise pricing

**Pros:** Buyers are the ones getting value from the platform, diversifies revenue from providers
**Cons:** Buyers expect directory data to be free, hard to gate without reducing growth

---

## 6. Data & Insights Products

**How it works:** Sell aggregated market intelligence derived from platform data.

**Products:**
- **Market reports:** "State of AI Agents in Healthcare 2026" — based on directory data + buyer behavior
- **Trend reports:** Which categories are growing, which agents are getting shortlisted most
- **Custom research:** Enterprise clients commission bespoke analysis
- **Benchmarking:** How does a company's agent portfolio compare to competitors

**Pricing:** $500-10,000 per report

**Pros:** High margins, leverages unique data asset, positions Orbys360 as thought leader
**Cons:** Requires significant data volume, manual effort to produce, not recurring

---

## 7. Hybrid Model (Recommended Long-Term)

Combine multiple models:

1. **Free claiming** to maximize provider adoption (Phase 1 — now)
2. **Freemium analytics** for providers once traffic justifies it (Phase 2)
3. **Sponsored placement** once directory has meaningful traffic (Phase 3)
4. **Lead gen fees** when buyer-to-provider connections are flowing (Phase 4)

This sequence maximizes growth first, then monetizes the network effects.

---

## Decision Criteria

When choosing which model to implement first, evaluate:

| Criteria | Weight |
|----------|--------|
| Does it require significant traffic first? | High |
| Does it create friction that slows growth? | High |
| Is it aligned with value delivered? | Medium |
| Implementation complexity | Medium |
| Recurring vs. one-time revenue | Low |
